# HostelTrade 

HostelTrade is a full-stack MERN application designed for hostel students to post, update, and manage tradeable items. The platform ensures secure user authentication, ownership validation, and efficient search functionality.

## Features

- User registration and login with JWT authentication
- Create, update, and delete item listings
- Listings are linked with verified users
- Keyword-based search to quickly find items
- Input validation and protected endpoints for secure operations

## Tech Stack

- Frontend: React.js, Bootstrap
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT, bcrypt
